📊 Measurement Methods Explained

Response Time (Top Value): Measured in your browser using performance.now() for this specific request. Includes network latency, DNS lookup, TCP connection, server processing, and browser overhead.
Server (Processing): Average of all requests measured on the server using Stopwatch. Shows only the time spent in the ASP.NET Core pipeline (pure processing time).

Data Size (Top Value): Pretty-printed JSON displayed in the UI for this request (includes whitespace and newlines for readability).
Server (Actual): Average of all requests - actual bytes written to the HTTP response stream (minified JSON sent over network).

💡 Client values are for the CURRENT request, while Server values are AVERAGES. This is why current request might be faster than the average! For performance testing, use the PowerShell scripts which reset metrics before each test.

Key Advantages of GraphQL

Single Request: GraphQL retrieves all related data in one request, reducing network overhead.
Flexible Queries: Clients specify exactly what data they need, avoiding over-fetching or under-fetching.
Bulk Operations: Create, update, or delete multiple resources efficiently in one mutation.
Real-time Updates: Built-in subscription support for real-time data synchronization.
